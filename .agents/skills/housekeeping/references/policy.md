# Configuration and decisions

Copy config.example.json to a private user-owned file outside Git, substitute `hostname` and real absolute paths, and create state_dir with mode 700. Python 3 and native macOS tools suffice. The script never creates configuration or installs anything. Required keys are host, state_dir and disk_root. Optional roots and repositories accept at most eight canonical, user-owned directories each. Choose narrow cache roots and repository roots, never all of home. Symlink paths and overlapping scan roots are rejected. An optional docker_socket names an existing local Unix socket; omit it to skip Docker. Docker remains stopped if unavailable.

Daily collection checks free bytes, native pressure level and swap. Review adds bounded process metadata, allocated storage under roots, local Git worktree registrations, and Docker logical inventory when configured. No file contents, process arguments, Git fetch/maintenance, or Docker lifecycle commands run. Measurements can be partial. An entry or time limit yields unknown, never a complete size estimate. Docker logical inventory is separate from physical host free space. Swap usage alone does not establish pressure.

Defaults warn below 15% free and become urgent below 25 GiB or at native critical pressure. ENOSPC during telemetry writes is urgent. Comparable timestamped samples show free and swap deltas; a free-space forecast is only an estimate. Reboots reset swap comparisons. Review compares only complete measurements with the same root list, budget and device. Unknown pressure remains visible even with healthy disk space.

The sole cleanup is rotation of this tool's own routine JSON reports, at most 12 files and 1 MiB total. Its private lock releases on exit or crash. Unknown state-directory entries stop writes. Keep incident evidence and recovery archives elsewhere; this directory is disposable routine telemetry. No standing host cleanup category is adopted by this example, and `--apply` is unsupported.

Caches, worktrees and Docker objects always need a user decision. Large protected roots remain in the report, with their size or an explicit unknown. Inventory is not eligibility proof. Worktree removal in a separately authorized task must use ADW for ADW-managed trees and wt otherwise. Preserve dirty/staged/untracked/ignored files, local-only refs/stashes, open review work, current roots, active workloads and every shared object source. Finished runs and branch names do not prove a merge. Squash merges need current repository-matched evidence covering the present HEAD and landing commit.

Preserve provider/T3/ADW histories and databases including WAL/SHM, credentials, recordings, models, recovery evidence, installed browsers/runtimes, active build caches, Docker volumes and stopped writable layers. Never remove swap or a Docker VM image, blanket prune, restart services, or repair Git. A maintenance lock does not exclude builds; a future executor would need per-candidate activity and dependency proof, immediate rechecks and adopted category authorization. Do not improvise an executor during a scheduled run.
